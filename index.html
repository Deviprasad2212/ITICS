Hotspot Details
1. NASA FIRMS Data Ingestion
Near real-time active fire anomalies from VIIRS (375m resolution, Suomi NPP & NOAA-20) and MODIS (1km resolution, Terra & Aqua). Detections include fire radiative power (FRP), brightness temperature, and confidence levels.
↓
2. OSM Geospatial Cross-Reference
Each hotspot is spatially queried against OpenStreetMap industrial infrastructure — tagged features include landuse=industrial, power=plant, man_made=works. Proximity distance and zone type are computed.
↓
3. AI Classification Engine
Random Forest classifier evaluates features: FRP magnitude, brightness temperature, OSM proximity distance, persistence across satellite passes, day/night context, and land cover type. Outputs: Industrial Fire / Uncertain / Natural Wildfire with confidence score.
↓
4. Alert Generation & Dissemination
Classified industrial fire events trigger priority alerts to disaster management authorities with full context: location, confidence, persistence data, and nearest infrastructure. Alerts are routed to NDMA/SDMA command centers.
Satellite Data Sources
  • VIIRS (Suomi NPP & NOAA-20) — 375m active fire product, ~4 passes/day over India
  • MODIS (Terra & Aqua) — 1km thermal anomaly product, MOD14/MYD14
  • OpenStreetMap — Overpass API queries for industrial land-use polygons
Classification Model

The classification engine uses a Random Forest model trained on 18 months of historical FIRMS data annotated with verified industrial fire incidents. Key features include Fire Radiative Power (FRP), background temperature delta, geospatial distance to known industrial polygons, persistence score (number of consecutive satellite passes), and time-of-day context. The model achieves 94.2% accuracy on the validation set with a false positive rate of 3.1% for industrial fire classification.
